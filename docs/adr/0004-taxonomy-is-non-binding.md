# 쟁점 택소노미는 참고 지식·체크리스트·평가 라벨로만 쓰고 분류를 강제하지 않는다

사전 정의된 쟁점 목록(I01~I17)에 관찰을 매핑하는 방식은 규칙 엔진의 변형이어서 목록 밖의 쟁점을 보지 못하고 에이전트의 도구 선택을 불필요하게 제한한다. 그래서 목록은 `knowledge/issue_patterns.yaml`의 참고 패턴으로 두고 ① 체크리스트 도구의 힌트, ② 커버리지 점검(고려되지 않은 듯한 패턴을 질문으로 1회 되돌림), ③ 평가 데이터셋 라벨, ④ 감사자 점검 항목으로만 쓴다. 분석에 패턴 참조가 없어도 유효하다.

## Consequences
- 근거 검증과 안전장치는 택소노미가 아니라 인용 검증기·권위 등급·시행일 필터·예산이 담당한다.
- 신규 쟁점 발생률과 커버리지 경고율을 지표로 추적해 패턴 목록을 갱신한다.

# 팀이 작성한 시나리오·유사사례는 법률 코퍼스가 아니라 평가 데이터셋이다

초안은 "팀 작성 유사사례"를 법률 코퍼스에 넣어 검색되게 했다. 그러면 가상의 테스트 케이스가 판례·결정례와 같은 권위를 가진 근거처럼 인용될 수 있다. 그래서 코퍼스는 공식 출처(법령·고시 = 권위 1, 판례·헌재·해석례·PIPC 결정 = 2, 안내서·분쟁조정 사례집 = 3)만으로 구성하고, 팀 작성 사례는 권위 등급 없이 평가·회귀 데이터셋으로만 쓴다. 검토 안내의 "유사 사례"는 권위 2·3의 실제 사례만 보여 준다.

## Consequences
- 인용 검증기는 권위 1·2 없이 권위 3만으로 "의무"를 단정한 분석을 통과시키지 않는다.
- 반사실 코퍼스 실험은 별도 인덱스로 수행하고, 평가 데이터와 코퍼스는 저장 위치부터 분리한다.

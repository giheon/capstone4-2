# 구간 실험은 체크포인트 분기와 단계 결과 저장으로 앞 단계를 다시 돌리지 않는다

> 실행 방식(영상마다 기준 실행 1회), 질문의 자동 응답, 구간 수는 [ADR-0014](./0014-experiment-sets-accumulate-runs-and-never-answer-for-the-user.md)가 바꿨다. 체크포인트 분기와 단계 결과 저장은 그대로다.

파이프라인의 한 구간(영상 정보 추출 · 법률 분석 · 계획 · 렌더)만 골라 부품 조합을 바꿔 가며 반복 실험하려면, 바꾸지 않은 앞 단계가 매번 다시 돌아서는 안 된다. M4의 "분기"는 같은 영상을 처음부터 다시 실행했다. 두 가지 재사용을 함께 쓴다.

1. **체크포인트 분기(구간 사이)**: 영상마다 기준 프로필로 한 번 실행하고(기준 실행), 다른 조합은 그 실행의 체크포인트 가운데 "처음 달라지는 구간의 진입 노드 직전" 것을 새 스레드로 복사해 거기서 이어 간다. 계획 모델만 바꾼 조합은 `plan` 직전에서 시작하므로 지각과 법률 분석은 실행되지 않는다. 질문에 대한 답도 기준 실행의 상태에 들어 있어 사람 입력을 다시 받지 않는다. 실행은 구간의 끝 노드 뒤에서 멈춘다(`interrupt_after`).
2. **단계 결과 저장(지각 안)**: 지각의 각 단계(프록시 · 검출 추적 · 인물 묶음 · OCR · 장면 설명 · 인물 속성)는 결과를 "입력의 해시"로 저장한다. 키는 영상 내용 해시, 읽는 앞 단계의 키, 쓰는 부품과 설정값으로 만든다. 같은 키가 있으면 계산하지 않고 가져온다. VLM만 바꾼 조합은 검출 · OCR · 묶음을 가져오고 장면 설명만 실행한다. 이 저장소는 실험뿐 아니라 모든 실행이 쓴다(같은 영상을 다시 올려도 지각은 다시 돌지 않는다).

## Considered Options
- 체크포인트 분기만: 지각은 병렬 가지(묶음 · OCR · 장면 설명)가 있는 서브그래프라서, 가지 하나만 다시 돌리는 지점의 체크포인트가 없다. 서브그래프 진입 직전에서 분기하면 검출부터 전부 다시 돈다(예시 영상 기준 20초 이상).
- 단계 결과 저장만(모든 노드를 키로 캐시): 법률 분석은 사람의 답과 도구 호출 이력에 의존하는 대화라서 입력 해시로 같은 실행임을 판정하기 어렵고, 캐시가 맞았다고 해도 "기준 실행의 그 상태에서 이어 간다"는 뜻이 분명한 체크포인트가 더 정확하다.
- 같은 스레드에서 과거 체크포인트로 되돌아가 다시 실행(LangGraph time travel): 기준 실행의 현재 상태가 분기의 것으로 바뀐다. 기준 실행은 비교의 기준이자 서비스 케이스일 수 있어 건드리면 안 된다. 그래서 체크포인트를 새 스레드로 복사한다.
- LangGraph 노드 캐시(`CachePolicy`): 노드의 반환값만 저장하므로 케이스 디렉터리에 쓰는 파일(프록시, 트랙)이 따라오지 않고, 키에 실행 컨텍스트(프로필)가 들어가지 않는다.

## Consequences
- 분기한 실행의 상태에는 기준 실행의 파일 경로가 들어 있어, 복사할 때 새 케이스 디렉터리로 바꾸고 앞 단계의 파일을 가져온다(큰 파일은 하드 링크). 공유된 파일을 제자리에서 고치면 다른 실행의 입력이 바뀌므로, 케이스의 JSON 쓰기는 모두 "새 파일을 쓰고 바꿔치기"이고 다시 계산하는 단계는 이전 출력을 먼저 지운다.
- 저장된 단계 결과는 코드가 바뀌어도 키가 같으면 재사용된다. 단계의 출력 형식이나 의미를 바꿀 때는 `STEP_VERSION`을 올려야 한다. 모델 호출이 실패해 설명이 빠진 결과는 저장하지 않는다.
- VLM 단계의 저장은 "같은 입력이면 같은 모델 출력을 다시 쓴다"는 뜻이다. 모델 출력의 변동을 재려면 저장소를 거치지 않는 반복 실행이 따로 필요하다(M5).
- 실험의 실행은 보통의 케이스로 남아 토폴로지에서 열어 볼 수 있다. 저장소(`data/artifacts`)와 실험 실행은 자동으로 지워지지 않는다.
- 비교 지표는 구간의 산출물에서 계산한 것이다(찾은 글자 · 인물 수, 요건의 대상, 결정의 대상, 검증 통과 수, 시간, 비용, 재사용으로 아낀 시간). 정답과의 비교는 데이터셋에 정답이 있는 항목(지금은 예시 영상의 지각 결과)에만 나온다. 법률 분석 · 계획의 정답 채점은 M5의 평가 데이터셋에서 한다.

### 13.2 비기능 요구사항
NFR-01 프라이버시(§11.4) · NFR-02 비용 60초 기본 프로필 ≈$0.25(목표), 절약 프로필 ≈$0.08. 케이스가 멈추는 비용 상한은 목표와 별개의 안전장치(기본 $1.00) · NFR-03 지연: 1분 영상 분석~계획 ≤5분(대기 제외) · NFR-04 재현성(모델·프롬프트 커밋·설정 fingerprint·데이터셋 버전 기록, 캐시 적중) · NFR-05 모듈성(core 독립) · NFR-06 한국어 · NFR-07 오프라인 테스트 · NFR-08 라이선스(AGPL·비상용 회피, 사용 시 명시) · **NFR-09 출력 동일성**(프레임 수·PTS·오디오 bit-exact·메타 동일, 마스크 외 PSNR 임계 이상, 검증 실패 시 미완료).

### 13.3 화면 — 서비스와 실험실 두 영역 (상세: [10-ui.md](./10-ui.md))

2026-11-06 사용자 지시로 화면을 두 영역으로 나눴다. **서비스**는 업로더가 영상을 넣고 출력까지 가는 흐름이고, **실험실**은 LLMOps 기능(토폴로지·실행 기록·실험·데이터셋·프로필)을 모은 연구자 영역이다. 아래 원래 목록은 서비스 영역에 그대로 들어갔고, 진단 패널은 실험실로 옮겨 확장했다.

원래 목록(참고):
업로드(영상 + 선택 메모) · 진행 타임라인(에이전트 단계·비용) · 대상 확인(인물·번호판·텍스트) · **질문 카드(동적, 썸네일·근거·영향 표시, 모름/나중에)** · 계획 검토(스크러버·미리보기·결정별 근거/사례/위험/대안·이월 질문) · 감사 결과 · 결과·보고서(초 단위 스크립트·검증 지표) · 진단 패널(LangSmith 링크·비용).

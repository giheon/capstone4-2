### Cheapest route to masks on CPU — what the primary sources actually support

- **No official SAM 2 CPU/MPS latency exists.** Meta's README/issues (#71, #564, #534, #687, PR #778) contain no maintainer timing; the only numbers are a user's "72.89 s/it" on CPU and Ultralytics' M4 Air table (SAM2-t 23.4 s/im, prompt-less default mode — likely everything-mode, my inference). Treat SAM 2.1-tiny on Apple CPU as seconds-per-frame, so it is viable only on keyframes.
- **Best Apache-2.0 "memory tracker" candidates for propagation:** EfficientTAM (S@512: 80.6 ms/frame on iPhone 15 Pro Max, README advertises Mac MPS support) and EdgeTAM (15.7 FPS iPhone, CoreML CPU+NPU). Both numbers are mobile NPU/CoreML, not x86/ARM CPU — expect worse on ONNX Runtime CPU.
- **Fastest permissive promptable image segmenter on a Mac with a number:** RepViT-SAM, M1 Pro CoreML 44.8 ms encoder + 11.8 ms decoder (Apache-2.0). MobileSAM: ~3 s on an Intel Mac i5 CPU.
- **Instance masks with a person class, permissive:** RTMDet-Ins-tiny (5.6 M, 35.4 mask AP, Apache-2.0), RF-DETR-Seg-N (33.6 M, 40.3 AP @312 px, Apache-2.0, ONNX/OpenVINO export), torchvision Mask R-CNN (BSD-3). The only official CPU ONNX figure among seg heads is YOLO11n-seg 65.9 ms — but it is AGPL-3.0.
- **Silhouette shortcuts** (MediaPipe Selfie 33 ms Pixel-6 CPU; PP-HumanSeg 15 ms Snapdragon) are semantic: they merge all people and need a per-detection crop to become per-person masks.
- **License blockers found:** EdgeSAM (S-Lab non-commercial), EdgeCrafter and DEIMv2 (non-commercial), Mask2Former weights (CC BY-NC 4.0), FastSAM (AGPL LICENSE despite README), YOLOE/Ultralytics (AGPL), RVM (GPL-3.0), SAM 3 (custom SAM License, gated).

### UNVERIFIED
- SAM 2 official CPU/MPS per-frame latency (none published); MPS output fidelity beyond the notebook warning.
- SAM 3 on CPU/MPS: only an unmerged PR (#627); upstream requires CUDA 12.6+.
- EdgeTAM and RepViT-SAM parameter counts (not stated in README/HF/paper text).
- RF-DETR-Seg "AP50:95" being mask AP (table header does not say "mask").
- CPU latency for RTMDet-Ins, RF-DETR-Seg, Mask R-CNN, Mask2Former, EfficientViT-SAM, EfficientSAM, TinySAM, SlimSAM (no primary numbers).
- Ultralytics YOLO11 docs do not state the CPU ONNX hardware; the P4d footnote is from the README's current (YOLO26) tables.
- Prompt mode used in Ultralytics' SAM-vs-YOLO M4 Air CPU test (not stated).
- MediaPipe SelfieMulticlass/DeepLab model-card licenses (only the Selfie card was read); ONNX export paths for RTMDet-Ins (mmdeploy) and torchvision Mask R-CNN were not checked.

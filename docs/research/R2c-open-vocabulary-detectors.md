### Caveats
- **Benchmark comparability:** YOLO-World/YOLOE report "Fixed AP" on LVIS-minival at 640; Grounding DINO family at 800×1333; SAM 3 LVIS numbers are mask/box AP with a different protocol. Grounding DINO-T's LVIS-minival is 27.4 in the paper but 28.8 in mmdet's re-evaluation ([mmdet](https://github.com/open-mmlab/mmdetection/blob/main/configs/mm_grounding_dino/README.md)).
- **Speed is almost all GPU.** The only CPU numbers from a primary source are Ultralytics' YOLO26 *detector* table (Intel Xeon ONNX), which is a proxy for YOLOE-26 of matching size, not a YOLOE-26 measurement ([paper Tab.7](https://arxiv.org/html/2606.03748)). Grounding DINO-T at 1.1 FPS on Orin NX GPU ([1.5 paper](https://arxiv.org/html/2405.10300)) suggests seconds-per-frame on CPU.
- **License fit for PrivFrame (Apache/MIT preferred):** Apache/MIT options with open weights are Grounding DINO 1.0, MM-Grounding-DINO, OWLv2, OmDet-Turbo, Florence-2. YOLO-World is GPL-3.0; YOLOE and anything through Ultralytics is AGPL-3.0; SAM 3 uses Meta's custom SAM License; GDINO 1.5/1.6/DINO-X weights are API-only despite Apache-2.0 repos.
- **OWLv2 checkpoint mapping:** which paper row the HF "ensemble" checkpoint equals is inferred from naming ("ST/FT ens" in scenic); the scenic README itself warns its evaluator numbers differ slightly from the paper.
- **Florence-2 detection is generative** (autoregressive decoding, `max_new_tokens`), so per-frame cost scales with output length; no official latency exists.
- **YOLOE-26 paper confusion:** the Jan-2026 arXiv [2602.00168](https://arxiv.org/abs/2602.00168) "YOLOE-26" is by Sapkota & Karkee (third party). Ultralytics' own source is the YOLO26 paper [2606.03748](https://arxiv.org/html/2606.03748) (2 Jun 2026) and the docs.
- **SAM 3.1** is confirmed: README entry dated 03/27/2026 and the [Meta blog](https://ai.meta.com/blog/segment-anything-model-3/) (Object Multiplex, up to 16 objects per pass; HF card claims ~7x faster at 128 objects on one H100).
- **Rex-Omni** (IDEA, CVPR 2026, 3B MLLM on Qwen2.5-VL-3B) has open weights but is under "IDEA License 1.0" plus the Qwen Research License, and the README gives no AP numbers ([README](https://github.com/IDEA-Research/Rex-Omni)).

### UNVERIFIED
- **YOLO-World v3:** no evidence; official README's latest is V2.1 (2025-02-08), no releases page entries ([README](https://raw.githubusercontent.com/AILab-CVC/YOLO-World/master/README.md)).
- **Grounding DINO 2:** no official IDEA repo/paper found; only a third-party guide claiming none exists.
- **Grounding DINO-tiny CPU latency:** no official number (README only says CPU-only mode is supported; community/GitHub-issue anecdotes of ~2–5 s/image were found but are not official).
- **Florence-2 CPU latency** and **OWLv2 inference speed:** none in any primary source checked (model cards, papers, scenic README).
- **SAM 3 on CPU / Apple Silicon:** no statement anywhere official; transformers examples merely fall back to `cpu`.
- **ONNX export** for Grounding DINO 1.0, OWLv2, and SAM 3 from official sources; **YOLO-World X params**; **DINO-X Edge availability** via the public API (README lists only Pro).
